# 月满中秋 · 灯谜趣答

一个零依赖的中秋灯谜答题小站：纯 HTML + CSS + 原生 JavaScript，配置与题库外置在 `data/` 目录，直接放进 GitHub Pages 就能跑。

## 怎么玩

1. 在首页挑一档难度：**易**、**中**、**难**，或者选 **混合模式**（三档混抽，易 4 : 中 4 : 难 2）。
2. 每局随机抽 15 题，选择题 30 秒、填空题 45 秒，答得越快分数越高。
3. 选择题只有一次机会；填空题有两次机会，第一次答错会告诉你谜底有几个字，但本题得分会打六折。
4. 答完看结算：总分、正确率、总用时、逐题回顾，还能把成绩存成一张竖版成绩图——成绩图里会连同本局所有错题的谜面与谜底一起列出，错题多时图片会自动加长。

中途想放弃，点右上角「退出本局」即可，本局成绩不会保留。

## 计分规则

- 单题得分 = 基础分 100 × 难度系数（易 1.0 / 中 1.3 / 难 1.6 / 混合 1.3）× 时间加成
- 时间加成最多 +50%，按剩余时间比例线性折算，答得越快加成越高
- 填空题第二次答对按 60% 计分，且不再叠加时间加成；答错或超时得 0 分

以上数值都在 `data/config.json` 里，随时可以改。

## 灯谜小知识

- 灯谜讲究「**谜面**—**谜目**—**谜底**」。谜面是题目本身，谜目告诉你要猜什么（打一字、打一成语、打一城市名……），谜底是答案。
- 最常见的三种扣合方式：**拆字**（把汉字拆开重组，如「一口咬掉牛尾巴」猜「告」）、**会意**（绕个弯说意思，如「风平浪静」猜「宁波」）、**谐音**（借同音字转义，如「打开窗户吹喇叭」猜「名声在外」）。
- 每题答完都会给一句「扣合思路」，看完就明白谜底是怎么来的，这也是灯谜最好玩的地方。

## 隐私说明

- 站点没有任何账号、统计和后端请求，只会在你自己的浏览器里读取 `data/` 下的配置与题库。
- 仅使用 localStorage 记录上一局出现过的题目编号，用于下一局尽量不重复出题；不保存历史成绩，也不上传任何内容。
- 浏览器禁用 localStorage 或使用隐私模式时，去重功能会静默关闭，答题不受影响。

## 目录结构

```
index.html              页面骨架（内联 SVG 灯笼，无外部图片）
css/                    基础排版、中秋夜色主题、答题组件样式
js/                     数据加载、抽题与流程、判定计分、渲染、成绩图
data/config.json        站点文案、难度、倒计时、计分、判定规则
data/riddles.json       题库（易 / 中 / 难三档，题量与编号由工具自动统计）
data/RIDDLE-FORMAT.txt  题库字段说明与新增题目模板
tools/                  题库校验、单元测试、本地预览服务器
```

## 本地预览

题库是外置 JSON，浏览器在 `file://` 下会拦截读取，所以请用自带的小服务器打开：

```
node tools/serve.mjs
```

然后访问 <http://localhost:8000/>。想换端口就写 `node tools/serve.mjs 8080`。

## 加题与调参

- 改题库：编辑 `data/riddles.json`，字段写法与可复制模板见 `data/RIDDLE-FORMAT.txt`。
- 加题编号不用自己数：`node tools/new-riddle.mjs` 会列出每档下一道可用编号，`node tools/new-riddle.mjs medium`（可加 `fill` 指定填空）会直接给出带正确编号的可复制模板。编号一律按题库现状推算，题量增减都不受影响。
- 改文案与规则：编辑 `data/config.json`，标题、副标题、每局题量、倒计时、难度系数、计分比例都在里面。
- 每题揭晓后停留多久再自动进入下一题，由 `reveal.autoDelayMs` 决定（默认 5000 毫秒）；成绩图落款网址在 `site.url`。
- 改完记得校验题库，避免 JSON 语法或字段问题：

```
node tools/validate-riddles.mjs
```

校验会检查 id 是否重复、必填字段是否齐全、选择题是否正好 4 个选项且包含正确答案、填空题答案是否为空，并报告各档题量分布。

## 测试

```
node --test tools/test-scoring.mjs
```

覆盖填空题归一化与多答案判定、字数提示、时间加成边界、填空第二次答对降分、难度系数换算等纯函数逻辑。

## 浏览器支持

现代浏览器（Chrome、Edge、Safari、Firefox 近两年的版本）均可，手机与桌面自适应；带 `prefers-reduced-motion` 时会自动关闭飘落动效。成绩图导出使用 Canvas，个别老旧浏览器或隐私设置下可能无法下载，页面会给出提示，不影响答题。
