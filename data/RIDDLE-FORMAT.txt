灯谜题库字段说明与模板
=========================

题库文件：data/riddles.json
站点配置：data/config.json

一、文件整体结构
----------------
{
  "version": 1,               // 题库版本号，随便写，方便你自己记录
  "updatedAt": "2026-09-23",  // 最近一次修改日期
  "riddles": [ ... ]          // 所有题目，顺序无所谓，程序会随机抽题
}

注意：JSON 不支持注释，上面和下面的 // 说明只是为了方便阅读，
真正写进文件时请不要带 //。


二、必填字段（选择题与填空题都要有）
------------------------------------
id          题目编号，全站唯一，格式为 <难度>-<数字>，如 easy-01。
            编号不用自己数：运行 node tools/new-riddle.mjs <难度>
            会按题库现状算出下一道可用编号，并直接给出可复制的模板。
difficulty  难度，只能填 easy、medium、hard 三个值之一。
type        题型，只能填 choice（选择题）或 fill（填空题）。
topic       谜目，例如“打一字”“打一成语”“打一城市名”。
question    谜面正文。
answer      谜底，必须与题库里的写法完全一致，程序用它与选项/答案列表比对。
explanation 一句话扣合解析，答完题会展示给玩家看。


三、选择题额外字段
------------------
options     恰好 4 个选项，必须包含 answer 本身，不能有重复选项。


四、填空题额外字段
------------------
acceptedAnswers  等价答案数组，可以写多个写法，玩家答中任意一个都算对。
                 标准答案 answer 会自动补进列表，所以至少写一个即可。
                 判定时会忽略首尾与中间空格、全角半角差异、中英文标点、
                 英文大小写，以及“的 / 是 / 了”这类虚词（可在 data/config.json
                 的 matching.stripWords 里调整）。


五、模板：选择题（编号请用工具生成）
------------------------------------
下面的 <下一道编号> 只是占位，实际编号请用 node tools/new-riddle.mjs easy 得到。

    {
      "id": "<下一道编号>",
      "difficulty": "easy",
      "type": "choice",
      "topic": "打一字",
      "question": "此处写谜面",
      "answer": "此处写谜底",
      "options": ["此处写谜底", "干扰项一", "干扰项二", "干扰项三"],
      "explanation": "一句话写清谜底是怎么扣出来的。"
    },


六、模板：填空题（编号请用工具生成）
------------------------------------
    {
      "id": "<下一道编号>",
      "difficulty": "easy",
      "type": "fill",
      "topic": "打一成语",
      "question": "此处写谜面",
      "answer": "正确答案",
      "acceptedAnswers": ["正确答案", "另一种常见写法"],
      "explanation": "一句话写清谜底是怎么扣出来的。"
    },


七、加题步骤
------------
1. 先看编号：node tools/new-riddle.mjs easy medium hard
   （或 node tools/new-riddle.mjs medium fill 直接拿到填空题模板）
2. 打开 data/riddles.json，在 "riddles": [ ... ] 里追加条目，
   注意上一条结尾要补一个英文逗号。
3. 在项目根目录运行校验：node tools/validate-riddles.mjs
   校验结果里同样会列出每档「下一道可用编号」。
4. 校验通过后刷新页面即可看到新题。

九、写题小提醒
--------------
· 选择题的干扰项最好和答案同类型、同字数，玩家才需要真的动脑。
· 填空题如果可能有一词多解，请把常见写法都写进 acceptedAnswers。
· 谜底里有标点时不必担心，判定会自动忽略。
· 页面文案与参数都在 data/config.json，改标题、每局题量、倒计时、计分方式
  都不用动代码；每题揭晓后停留多久再自动进入下一题，见 reveal.autoDelayMs。
